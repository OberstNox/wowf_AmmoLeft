# Ammoleft Forever changelog

## 2.0.2

- Fixed merchant price displays and purchase summaries to use the Forever currency API.

## 2.0.1

- Moved the counter preview below the appearance sliders and labeled its sample count.

## 2.0.0

- Added shared profiles, settings copying, and per-character position copying.
- Added compatible reserve ammunition to the counter tooltip.
- Added separate alert sounds, durations, optional pulses, and the `{count}` message placeholder.
- Added manual restock quotes and optional automatic restock with a spending cap.
- Updated the counter, alerts, minimap button, and settings to match the dark green and bronze icon.

## 1.3.2

- Added an item tooltip when hovering over the counter's ammunition icon.

## 1.3.1

- Renamed the addon to Ammoleft Forever in the AddOns list and settings.
- Added a custom arrow-and-cartridge icon to the AddOns list.

## 1.3.0

- Added optional Low and Critical text alerts with custom messages and previews.
- Added a movable preview that sets the shared alert position.
- Reused the selected warning sound for Low alerts and kept the existing Critical sound behavior.

## 1.2.0

- Added a draggable minimap button that opens AmmoLeft settings and saves its position per Hunter.

## 1.1.0

- Added the AmmoLeft settings page and `/ammoleft` shortcut.
- Added count colors, ammo thresholds, optional critical warning sounds, counter size, and background opacity.
- Preserved existing per-character counter positions when upgrading from 1.0.0.
- Credited OberstNox in the addon manifest and settings page.

## 1.0.0

- Added a movable count of the selected ammunition for Hunters in WoW Forever.
- Added fixed low-ammo colors and `/ammoleft reset` to restore the counter position.
